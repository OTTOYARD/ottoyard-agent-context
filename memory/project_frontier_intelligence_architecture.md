**THE ARCHITECTURE (honest, diligence-proof — 3 of 4 lenses converged):** a 3-tier runtime-assurance stack with strict authority — **only the deterministic core enacts.**
- **Tier 1 deterministic core** = spine + sole actuator: sub-second reactive loop, L1 shield, per-vehicle stall/DCFC assignment (a Linear Assignment Problem = polynomial → greedy PROVABLY near-optimal → AI only TIES here, owns it outright), reservation honour, fault auto-reroute, energy-plan follow. ~99.75% of enacted decisions. Every Tier-2/3 output is ADVISORY and must pass back through the shield.
- **Tier 2 cuOpt** = batch PLANNER for the ONE genuinely NP-hard regime: the **compressed overnight wave under charger scarcity** (resource-constrained scheduling / flexible job-shop: ~100 drained vehicles time-sharing scarce DCFC/L2/bays/staff under a cumulative energy cap + hard morning-deploy due-dates). Greedy first-fit is arbitrarily suboptimal (can't sequence in time, can't save DCFC for who needs it, can't shape load). **cuOpt today is MIS-POINTED at per-tick LAP (a category error — that's why it ties + its async loop loses the race). Fix = re-point, not abandon.** Off the hot path (solve-window cadence) so async latency is irrelevant.
- **Tier 3 Nemotron** = advisory human-interface/semantic layer FOREVER (never actuates, never the optimizer numbers): (a) exception/long-tail triage co-pilot (today's exception path is pure seeded-random dice — real opportunity), (b) coarse ONCE-PER-REGIME discrete posture selection {daytime_churn|pre_wave_prestage|overnight_wave|morning_commit}→vetted preset (RETIRE the continuous dial-railing "conductor" — it pins rails while narrating the opposite = diligence liability), (c) NL explainability over the audit trail, (d) the approval co-pilot (built).
